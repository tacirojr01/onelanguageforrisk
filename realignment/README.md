# Realignment notes

When a source under revision is published (ISO 31000 third edition; the NIST IR 8286 series; COSO's new edition), the procedure of chapter 24 (open problem 4) runs and the catalog's next release lists, component by component, the old citation, the new one and the class of change (patch, minor, major). The same note is published for any source revised or withdrawn later.
