# Mapping sheets by entry program

One sheet per entry program of chapter 21, saying for each of the forty-seven components whether the program already satisfies it (`satisfied`), satisfies it under another name (`satisfied-as`, with the program's own name in `program_element`), or lacks it (`missing`).

`TEMPLATE.csv` lists the forty-seven codes. Sheets to be published, in the order of chapter 21:

- enterprise risk management program (COSO-based)
- ISO 31000 program
- NIST RMF / CSF program
- Basel-supervised bank
- quality or safety program (FMEA, hierarchy of controls)
- business-continuity program
- project risk program (PMI)
- mid-sized company with a spreadsheet register

*Status: templates only; the sheets are being produced and will be released with catalog 1.1.*
